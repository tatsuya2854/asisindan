美脚の魔女図鑑 - アップロード手順

このフォルダの中身を、まるごと同じ階層にアップロードしてください。

  leg-witch.html   ← ページ本体（index.html にリネームしてもOK）
  app-icon.png     ← ホーム画面に追加したときのアイコン
  img/             ← イラスト16枚（結果・詳細・シェアカード用）
  img/t/           ← サムネイル16枚（図鑑の一覧用）

・フォルダ構成を変えなければ、そのまま動きます。
・画像を差し替えたときは img フォルダごと入れ替えてください。
・img の場所を変える場合は leg-witch.html の中の
    var IMGBASE = "img/";
  の1行だけ書き換えてください。
・HTMLだけを開くと画像は表示されません（imgフォルダとセットで動きます）。
