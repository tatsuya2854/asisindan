美脚の魔女図鑑 - アップロード手順

このフォルダの中身を、まるごと同じ階層にアップロードしてください。

  index.html            ← ページ本体
  leg-witch.html        ← index.html と中身は同じ（どちらで開いてもOK）
  ogp.jpg               ← X / LINE にリンクを貼ったときに出るカード画像
  manifest.webmanifest  ← ホーム画面に追加したときの設定
  app-icon.png          ← ホーム画面のアイコン
  img/                  ← イラスト16枚（結果・詳細・シェアカード用）
  img/t/                ← サムネイル16枚（図鑑の一覧用）

・フォルダ構成を変えなければ、そのまま動きます。
・画像を差し替えたときは img フォルダごと入れ替えてください。
・img の場所を変える場合は index.html の中の
    var IMGBASE = "img/";
  の1行だけ書き換えてください。
・HTMLだけを開くと画像は表示されません（imgフォルダとセットで動きます）。

シェア画像について
―――――――――――――――――――――――――――――――
・結果画面の「シェア画像を作る」で、1080x1920 のカードをその場で書き出します。
・スマホでは共有シートが開き、そのままストーリーズに送れます。
  対応していない環境では画像のダウンロードになります。
・canvas を使うので、file:// で直接ひらくと書き出せません。
  必ずサーバー（httpsのURL）に置いてから確認してください。
  file:// のときは自動で「スクショしてね」の案内に戻ります。

―――――――――――――――――――――――――――――――
結果を直接ひらくURL
―――――――――――――――――――――――――――――――
・https://～/#w=SYNT のように #w= のうしろに4文字コードを付けると、
  その魔女の結果画面を直接ひらけます。
・シェアされたリンクから来た人には「わたしも診断する」ボタンが出ます。

―――――――――――――――――――――――――――――――
数字を変えたいとき（index.html の中）
―――――――――――――――――――――――――――――――
  var AD_URL   = "..."      PR枠のリンク先
  var AD_EVERY = 1          PR枠を出す頻度（1=毎回、3なら3回に1回）
  var IMGBASE  = "img/"     画像の置き場所

OGP画像を差し替えるとき
―――――――――――――――――――――――――――――――
・ogp.jpg を 1200x630 の画像に置き換えるだけです。
・独自ドメインに置く場合は、index.html の
    <meta property="og:image" content="ogp.jpg">
  を絶対URL（https://～/ogp.jpg）にすると確実です。
