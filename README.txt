美脚の魔女図鑑 - アップロード手順

このフォルダの中身を、まるごと同じ階層にアップロードしてください。

  leg-witch.html   ← これがページ本体（index.html にリネームしてもOK）
  img/             ← 大きいイラスト16枚（結果画面・詳細・シェアカード用）
  img/t/           ← 軽いサムネイル16枚（図鑑の一覧用）

・フォルダ構成を変えなければ、そのまま動きます。
・img の場所を変えたい場合は leg-witch.html の中の
    var IMGBASE = "img/";
  の1行だけ書き換えてください。
・HTMLだけを開くと画像は表示されません（imgフォルダとセットで動きます）。
